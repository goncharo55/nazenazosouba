きょうの用語解説

逆張り（コントラリアン投資）とは

逆張りとは、相場の流れに逆らって売買する手法のことで、株価が大きく下げた銘柄をあえて買う、あるいは大きく上げた銘柄をあえて売る、といった動き方を指す。反対に、上昇している銘柄をさらに買い、下落している銘柄をさらに売る手法は「順張り」と呼ばれる。順張りは流れに乗る分、転換点を見誤ると損失が膨らみやすく、逆張りは下げ止まりを早くとらえられれば値幅を取りやすいが、下落の途中で買ってしまうと傷が深くなりやすいという、裏表の関係にある。

きょうのソフトバンクグループやSUMCO、レゾナックのように、前日に大きく売られた銘柄に翌日買いが入る値動きは、まさに逆張りの資金が入った結果として説明できる形だ。ただし、こうした値動きは「下げ切った」ことを保証するものではない。前日の下落率と比べて戻りが小さい銘柄（きょうのアドバンテストや東京エレクトロンのように）もあり、逆張りで買った値段からさらに下に沈むことも珍しくない。値動きの仕組みを知ることと、実際にその銘柄を売買すべきかどうかは別の話であることを押さえておきたい。
