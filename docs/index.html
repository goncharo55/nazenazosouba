JP日本市場：半導体が主導した反発を帳消しに、ソフトバンクGは年初来安値

25日の東京株式市場は大きく値を消した。日経平均株価は前営業日比1,633.01円（2.78%）安の57,011.62円で取引を終え、前日に記録した3.91%の上昇のうち、7割近くを吐き出す結果になった。TOPIX(ETF)も0.30%安の394.70円で小幅に反落している。

値を消した中心は、前日まさに相場をけん引していた半導体関連株だった。半導体テスターのアドバンテストは12.94%安、半導体製造装置の東京エレクトロンは12.53%安。両社とも前日はそれぞれ12%超の上昇を記録しており、1日違いでそっくり裏返るような値動きになった。電子部品の村田製作所は14.20%安、半導体パッケージ基板のイビデンは16.01%安、半導体検査装置のレーザーテックも11.67%安と、前日の上昇率上位がそのまま下落率上位を占める構図になった。中でもソフトバンクグループは14.83%安まで売られ、年初来安値を更新している。

対照的に値を上げたのは、医薬品・ヘルスケア株とITサービス株だった。大塚ホールディングスは6.36%高、中外製薬は6.02%高、第一三共も5.79%高と並び、受託開発のSHIFTも7.54%高、野村総合研究所も6.47%高で引けた。半導体株から抜けた資金が、業績の振れが比較的小さい業種に向かった形で、前日のニューヨーク市場で見られた「ハイテクから工業・ヘルスケアへ」という資金の流れが、1日遅れで東京でも再現されたとみることができる。

きょうの用語解説

きょうの用語解説：セクターローテーションという考え方

相場全体が大きく動くとき、すべての銘柄が同じ方向に動くわけではない。ある業種から資金が抜け、別の業種に向かう動きを「セクターローテーション」と呼ぶ。値上がりしていた銘柄が売られ、売られていた銘柄が買われるため、指数全体の動きだけを見ていると実態を見誤りやすい。

今日の値動きは、その分かりやすい例になった。24日のニューヨーク市場では、半導体株が大きく売られる一方でNYダウは5万ドル台を維持し、ハイテク比率の低い工業株・ヘルスケア株には買いが入った。25日の東京市場では同じ構図がそのまま再現され、アドバンテストや東京エレクトロンといった前日の上昇を主導した半導体株が軒並み売られ、代わりに医薬品株やITサービス株が値を上げている。半導体株が2日間で値動きをほぼ帳消しにする一方、医薬品株には資金が流れ込んだ――この組み合わせが、セクターローテーションの実例といえる。
