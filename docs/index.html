きょうの用語解説

「金銀レシオ」って何?

金銀レシオとは、金1オンスの価格が銀何オンス分に相当するかを示す指標で、金価格を銀価格で割って求める。歴史的には60倍から80倍あたりで推移することが多く、レシオが上がれば銀が金に対して割安、下がれば銀が割高と見る目安として使われる。

きょうはまさにその動きが数字に表れた日だった。金は1オンス3,703ドルまで4.7%上昇したのに対し、銀は44.63ドルまで11%を超えて上昇し、上げ幅は銀のほうがずっと大きかった。結果として金銀レシオは約83倍まで下がった計算になる。銀は金と同じ「資産逃避先」としての顔を持つ一方、太陽光パネルや電子部品といった工業用途の需要にも価格が左右されやすいという、金にはないもう一つの顔を持つ。きょうのような銀の急伸は、金と同じ流れに加えて、工業用需要をめぐる思惑が重なった結果とも読める。
